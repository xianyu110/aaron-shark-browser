# Aaron & Shark AI 展示面（浏览器版）

这是桌面版「Aaron 和鲨鱼 AI 展示面」的本机浏览器版。它把图片编辑需求整理成一份可直接复制到 ChatGPT、Gemini 或其他图像模型的 Image 2.0 提示词。

## 功能

- 上传主图并预览
- 在主图上拖拽绘制红圈，标记重点编辑区域
- 添加脸部参考图，并设置主参考
- 添加服装、配饰参考图
- 选择画面风格和画幅比例
- 生成结构化编辑提示词
- 一键复制提示词
- 导出项目 JSON，便于保存当前工作记录
- 适配桌面和手机浏览器

## 本机运行

直接双击 `index.html` 即可打开。

也可以在项目目录运行本地服务：

```powershell
python -m http.server 5173
```

然后访问：

```text
http://localhost:5173
```

## 使用流程

1. 上传一张主图。
2. 在主图上拖拽绘制红圈。
3. 添加脸部、服装或配饰参考图。
4. 输入希望 AI 完成的画面修改。
5. 选择风格和画幅比例。
6. 点击「生成提示词」。
7. 复制提示词，并在 ChatGPT / Gemini 中上传同一组图片后使用。
8. 需要留档时点击「导出项目」。

## 隐私说明

这是纯前端本地工具。图片会在当前浏览器页面中处理，不会自动上传到本项目服务器，也不会自动发送到 ChatGPT 或 Gemini。

## 当前限制

- 浏览器版负责整理图片工作流和提示词，不负责自动登录或操作 ChatGPT / Gemini。
- 导出的 JSON 记录文件名、标注信息和提示词，不会把图片文件本身打包进去。
- 关闭页面后，未导出的当前项目不会自动恢复。
